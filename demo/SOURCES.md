# Demo material sources

Public Pexels photos (Pexels License: free to use and modify, not to be resold as-is), the YouCam try-on results produced from them, one frontal illustration generated by an AI image tool from an Unsplash side-view photo (labelled Simulated, see `final/README.md`), and one AI-generated expected-look image (`expected/`, labelled Simulated).

- Unsplash photo `uCt9uA9r1Rw` (Unsplash License: free to use and modify): a side-view original that is **not shipped**; only the AI-generated frontal illustration made from it is used (`final/vitiligo_F_*`, labelled Simulated). The illustration is not the person's original photo and does not claim to be.
- `photos/vitiligo_20551205.jpg`: https://www.pexels.com/photo/portrait-of-brunette-man-20551205/ (Pexels License, face cropped)
- `photos/standard4/`: the standard set of four, each a Pexels photo cropped to 3:4 around the face landmarks, no EXIF:

  | File | Original | Licence | sha256 (after cropping) |

  | `albinism_F_5273693.jpg` (woman, top), `albinism_M_5273693.jpg` (man, bottom) | https://www.pexels.com/photo/expressive-albino-couple-embracing-in-studio-5273693/ | Pexels License | 23997446…, 1c498877… |
  | `vitiligo_M_20551205.jpg` | https://www.pexels.com/photo/portrait-of-brunette-man-20551205/ | Pexels License | 62c6f40d… |
  | `vitiligo_F_5084654.jpg` | https://www.pexels.com/photo/a-woman-in-white-coat-looking-with-a-serious-face-with-her-arms-crossed-5084654/ | Pexels License | 8f25b7ed… |

- Demo mode, "Try a demo photo first": the very-light-skin entry uses `standard4/albinism_F_5273693.jpg`; the uneven-tone entry uses `vitiligo_20551205.jpg`.
- `web/img/cover_albinism.jpg`, `web/img/cover_vitiligo.jpg`: the app cover images, cropped to 3:4 (720×960) from Pexels 5273693 and 20551205 (Pexels License, modification allowed). The cover carries the note "for illustration only; the people in the photos have no connection to this project". `cover_vitiligo.jpg` is `photos/standard4/vitiligo_M_20551205.jpg` scaled to 720×960.
- `replay/`: results of real YouCam Makeup VTO calls (smoothing 0). `replay/<entry>/exact/` holds results recorded for every combination of the front-end options (`tools/record_demo_replays.py`); demo mode prefers the result for exactly the same options. `index.json` lists the options and sha256 of each image.
- `face/`: a real YouCam Face Attribute response (10 credits), with URLs removed.
